# Demo video script (10 minutes)

Record at a phone-size browser window (375 px) or on a phone. Split the speaking parts between both partners.

| Time | Who | Show | Say |
|---|---|---|---|
| 0:00–0:45 | A | README, Home | Problem (running is boring, runs vary in length, people stop early); what RunX does |
| 0:45–2:00 | A | Home: duration chips, Other length, "Story ends at", Try the demo | Durations 20/30/45 and custom; the story is fitted to the run |
| 2:00–3:30 | B | Demo run: captions, windmill progress, Pause/Resume, Stop sheet | Accelerated clock; captions for every line; Stop finishes the current line; only Save before the opening ends |
| 3:30–4:30 | B | Save for next time → summary → Home Continue card → Resume (recap bubbles, too-short message with 15 min) | Checkpoints CP1–CP3; recap only after 3 days; never skips required scenes |
| 4:30–5:30 | A | Finish the story now; post-run summary | Compressed ending; episode complete only after it fully plays |
| 5:30–6:30 | B | Sign up / log in, progress on a second browser, guest import prompt | Supabase Auth (JWT), per-user progress with row-level security |
| 6:30–7:30 | A | `/editor` as editor: edit a scene, break a prerequisite → Publish blocked → fix → publish; runner account gets 403 | Third role; validator blocks invalid manifests; version bump |
| 7:30–8:30 | B | `/api/docs`, curl `/api/episodes` and 401 on `/api/progress/ep1` | Public API and OpenAPI |
| 8:30–9:30 | A | `buildTimeline` tests, coverage, a PR with red→green commits, GitHub Actions run, CodeQL, preview comment | TDD, multi-stage CI/CD, security scan, preview deploys |
| 9:30–10:00 | B | Board, milestones, retro | Process, what we learned, next steps |
